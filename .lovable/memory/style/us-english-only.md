name: US English spelling only
description: All user-facing copy and AI-generated narrative must use American English spelling, never British spellings.
type: preference
---

All user-facing copy, prompt text, and AI-generated narrative uses U.S. English spelling.

Convert: practising→practicing, behaviour→behavior, favour→favor, colour→color, centre→center,
organise/organisation→organize/organization, recognise→recognize, realise→realize, travelling→traveling,
counsellor/counselling→counselor/counseling, honour→honor, neighbour→neighbor, analyse→analyze,
emphasise→emphasize, prioritise→prioritize, apologise→apologize, labelled→labeled, programme→program,
amongst→among, grey→gray, jewellery→jewelry, theatre→theater, pretence→pretense.

Do NOT change: proper nouns, astrology/Vedic Sanskrit terminology, code identifiers not shown to users,
or quoted source material that must stay verbatim.

**How to apply:** every AI prompt that generates narrative carries a `US ENGLISH RULE` line beside the
em-dash rule. Add it to any new prompt.
